# 毛记忆 PawMemory

一个宠物记忆留存与陪伴的手机端 H5 原型，基于"记忆银行"核心理念设计：宠物在世时免费存下声音、照片、文字，离世后这些记忆成为可回味的专属纪念。

**在线预览**：https://aohanguo51-maker.github.io/mjy/

## 功能概览

### 首页（类信息流）
- 发现 / 关注 / 附近 三个 Tab
- 附近页接入**高德地图真实 POI 搜索**，支持按 全部/宠友/宠物店/医院/纪念服务 筛选查看真实同城地点
- 定位失败时优雅降级为示例数据，不影响使用

### 陪伴
- 文字聊天 + 真实语音录制/上传（浏览器 MediaRecorder API），是驱动"声音克隆进度"的真实数据源
- 轻量娱乐向的"声音翻译"功能（预设选项，不写入记忆银行，避免和真实录音功能语义混淆）

### 记忆银行（核心页）
- 总量卡：照片/声音样本/文字记录 三类计数，实时更新
- 声音克隆进度条：录音/上传每次 +1 段，向"可用于告别服务"的质量阈值推进
- 家人协作：邀请家人共同记录，支持**真实二维码分享**（扫码加入）
- 近期存入时间线：真实动态渲染，不是写死数据
- 健康档案联动：健康页新增记录会同步计入记忆银行总量

### 健康档案
- 日常指标记录（吃饭/喝水/排便/体重/心情）
- 医疗记录时间线（疫苗/体检/手术/生病）

### 我的
- 宠物档案管理，支持**多宠物**（每只宠物独立档案：品种/性别/年龄/体重/绝育状态/驱虫周期/过敏史）
- 记忆空间容量条（跟真实照片数联动）
- **消费记账**：账单按宠物分类展示，支持按宠物筛选并实时重算总额，参考「肥崽」的多宠分摊设计
- 月付会员 / 一次性告别纪念服务 两档付费（UI 展示，未接入真实支付）

### 多宠物标签系统
- 记忆银行时间线、消费记账列表，每条记录都可标注归属宠物（圆形头像标签），方便多宠家庭区分记忆归属

### AI 养宠问答（已整合进健康档案页）
- 位于健康档案页内，夹在“今日日常/饮食偏好”和“医疗记录”之间，形成“记录→问诊→查病史”的自然阅读流（之前曾放在陪伴页，后因场景不贴合迁回健康档案页）
- 进入健康页就自动带出宠物完整档案（品种/年龄/绝育状态/驱虫周期/过敏史等）作为上下文
- 用户点选症状（呕吐/拉稀/食欲不振/咳嗽/精神萎靡/瘙痒抓挠）+ 简单描述，生成的建议会引用该宠物的具体档案信息，而非通用建议
- 含免责声明，明确不能替代执业兽医诊断

## 技术实现

纯前端单文件 H5（HTML + CSS + JS），无需构建工具，本地直接打开 `index.html` 即可预览。

已接入的真实 API：
- **高德地图 Web服务API**（周边搜索）：已配置真实 Key，切到附近页会引导用户开启定位权限，拒绝/失败时会显示引导条+重试按钮，优雅降级为示例数据
- **浏览器原生定位** `navigator.geolocation`
- **浏览器原生语音识别** `SpeechRecognition`（陪伴页麦克风输入）
- **浏览器原生录音** `MediaRecorder`（真实存声音样本）
- **二维码生成**（`api.qrserver.com` 图片接口，用于邀请家人扫码加入）

尚未接入（预留架构，未来可扩展）：
- 声音克隆/语音合成（可接阿里云百炼 CosyVoice 或 MiniMax）
- AI 对话大模型（可接通义千问/DeepSeek 等，目前院伴页对话+AI养宠问答都是前端规则引擎模拟）
- 真实支付（微信支付 JSAPI/H5支付）

⚠️ **安全提醒**：本仓库为公开仓库，`index.html` 中的 `AMAP_KEY` 会被任何人看到。当前风险可控（最坏情况是消耗免费额度），建议定期在高德控制台重置该 Key，或后续升级为有后端代理的架构。
