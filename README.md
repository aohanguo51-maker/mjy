# 毛记忆 PawMemory

> 一个宠物记忆记录 App —— 存下它的照片、声音和日常，也和其他养宠人一起分享。

## 在线体验

**纯前端版（无需登录，数据存本地浏览器）**
👉 https://aohanguo51-maker.github.io/mjy/

## 两个版本

| | 纯前端版 | 全栈版 |
|---|---|---|
| 位置 | 根目录 `index.html` | `fullstack/` |
| 数据存储 | 浏览器本地（localStorage） | 腾讯云 CloudBase 数据库 |
| 登录 | 无 | 手机号 + 验证码 |
| 换设备 | 数据不同步 | 数据云端同步 |
| 适用 | 快速体验、演示 | 真实用户使用 |

## 功能

**记录**
- 多宠物档案：名字、品种、生日、体重、绝育状态、过敏史
- 记忆银行：照片、录音、文字，按时间线归档
- 相册：照片和视频统一管理，支持编辑和删除
- 健康档案：疫苗、体检、病历，可拍照留存
- 消费记账：按宠物分类统计花销

**陪伴**
- AI 养宠问答：结合宠物档案给建议
- 声音克隆：录下它的叫声，可设为专属提示音
- AI 生成纪念视频（演示阶段）
- 「最后的告别」：为离开的毛孩子做一份纪念

**社区**
- 发布动态：图片 / 视频 / 话题标签
- 分类浏览：猫 / 狗 / 兔子 / 仓鼠 / 商家
- 点赞、评论、关注
- 附近：基于高德地图找宠物店和医院

## 技术

**前端**：原生 HTML/CSS/JS 单文件，无构建步骤，移动端优先（390×844）

**后端**（全栈版）：腾讯云 CloudBase
- 10 个云函数：登录鉴权、用户、宠物、记忆、社区、互动、医疗、账单、内容审核、数据初始化
- 10 张数据表（文档型数据库）
- 云存储：图片
- 静态托管：前端页面

**第三方**：高德地图 API（附近的宠物店和医院）
