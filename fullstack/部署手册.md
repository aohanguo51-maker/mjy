# 毛记忆 PawMemory —— 后端部署操作手册

> 环境 ID：`pawmemory-d5gjmq8i444ffb334`（上海，体验版，6个月免费）
> 全程在**你自己的电脑终端**操作，密钥不经过我这边。

---

## ⚠️ 第 0 步（必做，否则登录页直接用不了）：开启匿名登录

CloudBase 规定未登录用户不能调用任何云资源。前端必须先做一次匿名登录拿到凭证，
而匿名登录需要在控制台手动开启（命令行无法代替）。

1. 打开 https://tcb.cloud.tencent.com/dev#/identity/login-manage
2. 选中环境 `pawmemory-d5gjmq8i444ffb334`
3. 找到「匿名登录」，把开关打开

不做这一步的后果：页面能打开，但点「获取验证码」会报
`PERMISSION_DENIED: Unauthenticated access is denied`，没人能登录。

## 开始前确认

你之前已经装好并登录了，先验证还有效：

```bash
tcb -v
tcb login --check
```

看到版本号和"登录成功"就继续。如果提示未登录，重新跑 `tcb login` 扫码。

> 这一步走 `tcb login` 的登录态，**不需要密钥**。

## 第 3 步：给云函数装依赖

先换国内源，不然很慢：

```bash

```

然后一共 10 个函数，会花几分钟：

```bash
for fn in auth user pet memory post interact medical bill audit seed; do
  echo "=== 安装 $fn ==="
  (cd functions/$fn && npm install --production)
done
```

## 第 5 步：设置登录密钥

这一步是为了让登录凭证不能被伪造。**8 个函数必须用同一个密钥**。

⚠️ 必须在函数部署之后做，否则报"函数不存在"。

先生成一个随机密钥：

```bash
openssl rand -hex 32
```

复制输出的那串字符（64位十六进制），然后（**不要加引号**）：

```bash
SECRET=粘贴刚才那串
for fn in auth user pet memory post interact medical bill; do
  echo "=== 配置 $fn ==="
  tcb fn config update $fn --envId pawmemory-d5gjmq8i444ffb334 --envVariables TOKEN_SECRET=$SECRET
done
```

**这串密钥自己存一下**（记事本/备忘录），以后加新函数要用同一个。

## 常见问题

**Q：点「获取验证码」报"云环境未开启匿名登录"**
第 0 步没做。去 https://tcb.cloud.tencent.com/dev#/identity/login-manage 开启匿名登录。

**Q：部署函数报 "function not found"**
先确认在 `fullstack` 目录下，且 `cloudbaserc.json` 存在。

**Q：npm install 很慢**
换国内源：`npm config set registry https://registry.npmmirror.com`

**Q：登录后一直转圈 / 报错**
八成是 TOKEN_SECRET 没设置或不一致。检查：
```bash
tcb fn detail auth --envId pawmemory-d5gjmq8i444ffb334
```

**Q：登录后马上又跳回登录页**
同上，密钥不一致导致凭证校验失败。

**Q：图片显示不出来**
云存储权限问题。控制台 → 云存储 → 权限设置 → 选「所有用户可读，仅创建者可写」

## 还没做的（上线前必须）

**内容安全审核**：用户发的动态和评论要过机审，这是 UGC 合规底线。
代码骨架已经写好（`functions/audit`），但需要你开通服务：
1. 去 https://console.cloud.tencent.com/cms 开通「文本内容安全」和「图片内容安全」
2. 创建子账号密钥（只给 TMS + IMS 权限）
3. 配到 audit 函数的环境变量：`CMS_SECRET_ID` / `CMS_SECRET_KEY`

**真实短信验证码**：现在是固定 `123456`，页面上有标注。
要接真实短信需要申请短信签名和模板（1-3个工作日审核），之后改 `functions/auth/index.js` 里发码那一段。
